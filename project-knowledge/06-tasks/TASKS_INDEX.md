# TASKS_INDEX.md

## Призначення

Цей файл є індексом task cards проєкту.

Task cards використовуються для фіксації:
- формулювання конкретної задачі
- меж виконання
- обмежень
- пов’язаних файлів
- ризиків
- короткого результату

Task cards не є authoritative source для архітектури, контрактів або екосередовища.
Для цього слід використовувати domain knowledge files.
