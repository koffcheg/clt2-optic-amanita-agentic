# TASKS_INDEX.md

## Purpose

This file is the project task-card index.

Task cards record:
- task statement;
- execution scope;
- constraints;
- related files;
- risks;
- short result.

Task cards are not authoritative sources for architecture, contracts, or ecosystem facts. Use domain knowledge files for that.

## Historical Task Card Access

Historical task cards are audit trail. They are not implementation sources, are not part of the card-driven route, and must not be read by an agent unless the user explicitly requests them.
