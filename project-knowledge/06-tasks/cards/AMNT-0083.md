## Summary

Fix `camera_id` propagation for file and image-sequence sources so the resolved
logical camera id reaches `FramePacket`, `CanonicalFrame`, and `TileRawView`.

## Goal

The tile route must receive a valid stable `{camera_id, tile_id}` radiometric
state key for file/image-sequence input without weakening tile state validation.

## In scope

- Add logical camera id support to `UriFileFrameSource`.
- Pass `cam_index` from `create_frame_source` into file sources.
- Add a runtime fallback in `process_single_frame` before `make_frame_packet`.
- Update focused unit tests for source, packet, runtime fallback, and tile
  camera id consistency.
- Verify by build and all unit tests only.

## Out of scope

- Runtime validation with Amanita/Comparator or dataset configs.
- Changes to `TileRadiometricStateStore` validation.
- Changing tile state key semantics.
- Generating camera ids in `PrepStage`.
- Fixing this only in `InputNormalizationStage` through `FrameContext`.
- Project Knowledge domain-card changes.

## User constraints

- Do not run runtime validation; use build and all unit tests only.
- Tests may be added or changed for this task.
- Keep `camera_id` as logical camera/source identity, not a tile index or
  temporary counter.
- Do not accept `camera_id = -1` in tile radiometric state keys.

## Source access rules

Canonical development only. Legacy sources are forbidden for code generation.

## Assumptions

- For file/image-sequence input, `cam_index` is the logical camera id when no
  hardware frame header provides one.
- A source-provided `FrameHeaderHint.camera_id` has priority over runtime
  fallback.

## Result

Implemented file/image-sequence `camera_id` propagation:

- `UriFileFrameSource` now accepts an optional logical camera id and emits it in
  `RawFrameEnvelope.header_hint.camera_id` when valid.
- `create_frame_source` now passes `cam_index` into file sources.
- `process_single_frame` now applies a pre-`make_frame_packet` fallback from
  `cam_index` only when the source did not provide `camera_id`.
- Added source, packet, runtime fallback, source-priority, and tile view
  consistency unit coverage.
- Added `source_factory.cpp` to existing unit-test source lists so factory
  coverage links against the production implementation.

Validation:

- `cmake --build build-dp1v2-tests`
- `ctest --test-dir build-dp1v2-tests --output-on-failure`

All 217 tests passed.
