## Summary

Apply bounded review fixes to the existing AMNT-0027 runtime slice: configurable
runtime visualization output, source/input-route separation, zero-based file
frame ids, stride-aware inverse-median frame budget, and CMake OpenCV usage
requirements cleanup.

## Goal

Keep the existing file/URI -> `FramePacket` -> `RadiometricStage` inverse-median
slice, but move hardcoded evidence output behind `ApplicationConfig.visualization`
and preserve source pixel depth instead of silently upscaling input frames.

## In scope

- Optional `ApplicationConfig.visualization` DTO and parser validation.
- Minimal `VisualizationSink` for radiometric full-frame stage outcomes.
- Pipeline integration that delegates output files to `VisualizationSink`.
- URI file source U8/U16 bit-depth preservation and frame id start at 0.
- Stride-aware bounded runtime frame budget.
- Focused tests for config, visualization sink, source bit-depth/frame-id, and route mismatch.

## Out of scope

- Full canonical visualization specification.
- Stage output contract changes.
- Async visualization, renderer configuration, DP2, IPC, tiles, CameraProSim,
  Stage0/binning, candidate extraction, segmentation, or measurement.

## User constraints

- Do not expand beyond the reviewed slice.
- Do not commit datasets or generated visualization artifacts.
- Leave full visualization domain/config cards for a follow-up after review.

## Source access rules

Canonical development mode. Legacy access is forbidden.

## Assumptions

- `ApplicationConfig.visualization` is a minimal runtime switch for this slice;
  it is not yet a full canonical visualization spec.
- `stages` must explicitly list `radiometric` for the current sink to write.
