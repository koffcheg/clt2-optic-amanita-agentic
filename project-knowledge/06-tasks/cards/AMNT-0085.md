## Summary

Add a concrete Stage 2 boundary adapter that converts `RadiometricStage` outcomes
into a stable downstream processing-frame boundary.

## Goal

Downstream code can consume `stage2.processing_frame` semantics instead of
directly depending on raw `RadiometricStage` output behavior.

## In scope

- Add `Stage2BoundaryAdapter` and `Stage2BoundaryWorkspace`.
- Implement completed radiometric output selection.
- Implement disabled/skipped raw bypass conversion to `CV_8U` RawIntensity.
- Add focused unit tests if needed.
- Wire the new implementation into existing CMake targets.

## Out of scope

- Project Knowledge domain card updates.
- Broad runtime integration of Stage 3 or later stages.
- Legacy `datapro1` design-source reads.
- Public exchange-format changes.

## User constraints

- Do not edit Project Knowledge except this task card.
- Do not create `IBoundaryAdapter`.
- `Stage2BoundaryAdapter` must be concrete and stateless.
- `FrameContext` must not store image payload.
- Conversion buffers must live in `Stage2BoundaryWorkspace`.
- `CV_8U` bypass must use shallow `cv::Mat` assignment.
- `CV_16U` bypass must use explicit scaling through `PixelRange`.
- New production comments and Doxygen comments must be English.
- Tests may be added or changed if needed.

## Source access rules

Canonical development. Legacy access is forbidden.
