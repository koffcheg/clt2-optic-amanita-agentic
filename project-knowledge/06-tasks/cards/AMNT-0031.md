## Summary

Remove the DP1 v2 runtime minimum warm-up frame cap so file sources can run to
source exhaustion, then run `inverse_median` over the `ForMedian` dataset using
one-off configs outside the repository.

## Goal

Process all available frames in `${AMANITA_RESOURCES_DIR}/datasets/raw/frames/ForMedian`
and write radiometric visualization outputs.

## In scope

- Minimal runtime code change to allow source-exhaustion runs.
- Build `datapro1_v2`.
- Create one-off application and pipeline configs outside the repository.
- Run the existing executable over the dataset.
- Report output location and counts.

## Out of scope

- Editing tracked repository config JSON files.
- Adding tests, fixtures, or new test infrastructure.
- Changing inverse median algorithm behavior.
- Changing DP1/DP2 exchange contracts.

## User constraints

- Do not change repository config files.
- Use `${AMANITA_RESOURCES_DIR}/datasets/raw/frames/ForMedian`.
- Process all frames present in the dataset.
- Use inverse median `stride=1`, `K=3`, and `ClipToInputRange`.
- Visualization must be enabled and must write radiometric stage output.

## Source access rules

Canonical development only. Legacy sources are forbidden for this task.

## Assumptions

- The dataset uses sequence filenames compatible with `C001_F%06d.tiff`.
- `AMANITA_RESOURCES_DIR` resolves through existing project resource config.

## Relevant context to read

- `datapro1_v2/src/runtime/runtime.cpp`
- `datapro1_v2/src/source/uri_file_source.cpp`
- `datapro1_v2/src/visualization/visualization_sink.cpp`
- `datapro1_v2/config/application_config_datapro1_v2.json`
- `datapro1_v2/config/pipeline_config_datapro1_v2.json`

## Planned changes

- Remove the runtime helper that caps execution at inverse-median warm-up length.
- Run with `RuntimeLoopLimits{.max_frames = 0, .max_empty_reads = 1}`.
- Create `/tmp` run configs with visualization enabled and unlimited.
- Run the configured dataset to source exhaustion.

## Files expected to be touched

- `project-knowledge/06-tasks/TASKS_INDEX.md`

- `datapro1_v2` now runs file/video sources until exhaustion/stop instead of
  stopping after inverse-median warm-up.
- Long-running stream sources may require an external stop signal.

## Validation approach

- Run the executable with one-off configs.
- Count input frames and visualization outputs.

## Result

Completed. Removed the inverse-median warm-up frame cap from `run_runtime_skeleton` so `datapro1_v2` runs until source exhaustion when `RuntimeLoopLimits.max_frames` is zero. Built `datapro1_v2` successfully. Created one-off configs in `/tmp/dp1v2_for_median_run` for `${AMANITA_RESOURCES_DIR}/datasets/raw/frames/ForMedian/C001_F%06d.tiff`, U16 input, `FixedK3`, `stride=1`, and `ClipToInputRange`. Ran the dataset to source exhaustion: 40 frame manifests were written under `/tmp/dp1v2_for_median_run/visualization`; 38 radiometric PNG outputs were written for frames 000002-000039, with frames 000000-000001 skipped as inverse-median warm-up.
