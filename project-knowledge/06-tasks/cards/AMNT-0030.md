## Summary

Implement bounded DP1 v2 reviewer fixes for file-source carrier preservation, visualization output directory validation, and visualization sink type mismatch handling.

## Goal

Preserve mono16 TIFF carriers through `UriFileFrameSource`, reject empty visualization output directories when visualization is enabled, and prevent PNG writes when visualization metadata does not match the actual `cv::Mat` carrier.

## In scope

- Bounded source adapter changes for still images and printf-style image sequences.
- Bounded application visualization config validation.
- Bounded visualization sink rendering/type guard behavior.
- Requested unit/visual-unit tests.
- Requested local validation commands.

- Canonical domain documentation changes.

## User constraints

- Use `cv::imread(..., cv::IMREAD_UNCHANGED)` for still images and printf-style image sequences.
- Keep `next_frame_id_` zero-based and aligned with printf sequence formatting.
- Keep `cv::VideoCapture` only for real video inputs.
- Do not introduce carrier conversions, color maps, or reinterpretation in the source adapter.
- Reject empty `application.visualization.output_dir` when visualization is enabled.
- VisualizationSink owns pixel-format/type mismatch handling.
- Add the explicitly named tests requested by the user.
