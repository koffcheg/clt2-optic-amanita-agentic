## Summary

Implement the `PrepStage` `full_frame`/`L0` path as a no-op route builder over
`CanonicalFrame`.

## Goal

The full-frame Prep route validates the canonical input carrier and returns a
non-owning pointer to the same `CanonicalFrame` without copying or changing
pixels.

## In scope

- Add `enabled` and `variant` handling to full-frame Prep processing.
- Reject non-`full_frame` variants without fallback.
- Validate basic `CanonicalFrame` image, geometry, and coordinate-space
  invariants.
- Preserve no-copy output semantics.

## Out of scope

- Runtime pipeline integration of Prep between Stage0 and radiometric.
- Tile descriptor generation and tile raw views.
- ROI or adaptive ROI routes.
- New automated tests or test infrastructure.
- Project Knowledge domain card edits.

## User constraints

- Change `datapro1_v2/src/stages/prep_stage.cpp`.
- Header comment updates are optional only.
- Do not use `clone()`, `copyTo()`, `convertTo()`, `resize()`, or
  `copyMakeBorder()`.
- Prep must not perform binning, pixel-format normalization, or bit-depth
  conversion.
- Do not create tests without separate approval.

## Source access rules

Canonical development only. Legacy access is forbidden.

## Assumptions

- `full_frame` is the only supported Prep route in this slice.
- Failed canonical-frame invariants should return `StageExecutionStatus::Failed`.
- `FrameContext` does not need mutation in this method.
