## Summary

Виконано підкрок Phase A / A.2: сформовано явний ingest/frame contract для DP1_v2 та додано явний статус результату побудови пакета кадру.

## Goal

Отримати вузький і безпечний контракт входу кадру в DP1_v2 з детермінованою діагностикою помилок, без змін DP1->DP2 wire/serializer контракту.

## In scope

- Розширення `FramePacket` і metadata hints для ingest boundary.
- Додавання типізованого статусу помилок (`FramePacketBuildError`, `FramePacketBuildResult`).
- Перевірки сумісності header/mat depth і допоміжний zero-allocation error string mapper.
- Build/smoke перевірка через repository-approved CMake preset flow.
- Оновлення Phase Tracker і Change Log.

## Out of scope

- Будь-які зміни DP1->DP2 schema/message-id/serializer layout.
- Реалізація source adapters (IPC/URI) як окремого підкроку.
- Temporal median / QoS / backend policy / side-by-side validation (поза A.2).
- Додавання зовнішніх залежностей.

## User constraints

- Не змінювати DP1->DP2 contract, schema/message-id/serializer layout.
- Не додавати нові зовнішні залежності.
- Не робити широкі рефакторинги.
- Не редагувати knowledge base поза `dp1_v2`, окрім явно погоджених файлів.

## Assumptions

- Поточний build host може мати обмеження по runtime OpenCV linker paths, тому smoke має залишатись легким і без environment hacks.
- Реальна e2e інтеграційна валідація залишається зовнішнім кроком.
