## Summary

Потрібно виправити попередню реалізацію тестового завдання: backend має бути PHP Laravel, а не Python без фреймворка.

## Goal

Надати Laravel backend skeleton із API endpoint-ами для банків, валют, курсів, відділень, статистики та профілю, зберігши Vue frontend і документацію запуску.

## In scope

- Видалити Python stdlib backend entrypoint.
- Додати Laravel app skeleton у `currency-dashboard/backend/`.
- Перенести seeded/fallback дані та API логіку в Laravel service/controller/routes.
- Додати Laravel scheduler command для оновлення курсів і відділень.
- Оновити Vue API base для Laravel dev server.
- Оновити README і AI-disclosure.

## Out of scope

- Зміни Amanita C++ production code/build/Docker/tests.
- Створення automated tests/test fixtures без окремого узгодження.
- Реальна SMTP-доставка, production DB schema і deployment hardening.

## User constraints

- Використати PHP Laravel для backend.
- Зберегти Vue frontend requirement.
- Мінімізувати зміни поза `currency-dashboard/`, README, LLM disclosure і task tracking.

## Assumptions

- Поточне середовище може не мати доступу до Packagist; Laravel dependencies описуються в `composer.json`, а runtime validation може бути обмежена syntax checks.
- Для MVP допустиме JSON-file storage у `storage/app/currency-dashboard/state.json` замість production DB.
- Регулярні оновлення реалізуються через Laravel scheduler command, який можна запускати вручну або через `schedule:work`.
