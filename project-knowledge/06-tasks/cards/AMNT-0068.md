## Summary

Apply minimal logging/profiling cleanup fixes for DP1 v2 before merge, keeping runtime behavior stable.

## Goal

Add file logging and complete small logging/profiling fixes without altering pipeline or stage logic.

## In scope

- Add RollingFileAppender in datapro1_v2-log.xml and attach to root logger.
- Introduce a unified sanitizer for structured log string values.
- Fix avg_frame_duration_ms denominator when frames are dropped.
- Add std::cerr fallback for bootstrap failures before/when log4cxx setup fails.

## Out of scope

- P3 operation-level profiling.
- Full P5 p95/p99/median aggregation.
- JSON/CSV profiling report writer.
- External trace integration.
- Changes to dp1_spent_time.
- Change of frame_duration_ns semantics.
- Broad refactoring or pipeline/stage algorithm changes.

## User constraints

- Follow LOGGING_POLICY.md and PROFILING_POLICY.md.
- Follow dp1.config.application.logging and dp1.config.application.profiling.
- Do not create appenders from C++ code.
- Keep existing logger levels unchanged.
- Do not create tests without explicit approval.

## Source access rules

Legacy access is forbidden for canonical development.

## Assumptions

- log4cxx config currently uses ConsoleAppender only.
- The required fixes can be implemented with minimal localized changes.
