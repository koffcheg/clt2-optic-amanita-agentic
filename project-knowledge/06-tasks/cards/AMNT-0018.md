## Summary

Local code-only canonicalization of the standalone `inverse_median` filter so it can be integrated into the canonical DP1 pipeline later.

## Goal

Keep the filter self-contained while aligning its public API and behavior with the current canonical `inverse_median` stage specification.

## In scope

- Remove non-canonical residual output modes from the filter.
- Add local route metadata needed for future pipeline integration.
- Add reset/reconfiguration helpers for geometry, pixel format, bit depth, range, and binning route changes.
- Add canonical result view metadata for residual and compatibility output.
- Add lightweight per-call timing fields.
- Move reusable `CyclicFrameBuffer` out of the inverse-median stage into runtime support code.

## Out of scope

- Pipeline integration.
- Runtime config parser integration.
- New stage interface hierarchy.
- New automated tests, fixtures, mocks, snapshots, or golden files.
- Domain knowledge card changes outside this task card.

## User constraints

- Keep filter behavior local; reusable runtime support may be added for `CyclicFrameBuffer`.
- Do not change pipeline/config/tests in this task.
- Follow current canonical Project Knowledge.

## Source access rules

Canonical DP1 sources only. Legacy access is forbidden for this task.

## Assumptions

- `datapro1_v2` does not yet have canonical `ProcessingFrame` DTOs, so local result metadata will be a bridge API.
- Compatibility wrappers may remain where useful, provided canonical behavior is preserved.

## Result

Completed. The filter now exposes canonical route metadata, reset helpers,
canonical residual view metadata, and lightweight timing fields. Non-canonical
`ShiftToPositive` and `ScaleToInputRange` output modes were removed.
`CyclicFrameBuffer` is now an explicit reusable runtime structure under
`dp1v2/runtime`, and `InverseMedianFilter` uses it instead of scattered private
ring-buffer fields.
`CyclicFrameBuffer` now stores metadata for geometry, OpenCV type, bit depth,
pixel format, range, and range policy, validates metadata at storage reset, and
validates stored frames against the configured geometry/type.

Validation: `cmake --build --preset host-debug-datapro1v2` completed
successfully.
