## Summary

Stage1 Prep currently exposes `FramePacket` in its stage contract even though
Stage0 Input Normalization emits `CanonicalFrame`. Add a concrete `PrepStage`
skeleton that supports only the full-frame route.

## Goal

`prep_stage.hpp` no longer depends on `FramePacket`, and the main
`datapro1_v2` target contains a concrete `PrepStage` implementation.

## In scope

- Replace Prep full-frame and tile input carriers with `CanonicalFrame`.
- Add concrete `PrepStage final : public IPrepStage`.
- Implement full-frame pass-through and explicit unsupported tiles route.
- Add `src/stages/prep_stage.cpp` to the main CMake target.

## Out of scope

- Runtime pipeline integration of Prep between Stage0 and radiometric.
- Tile descriptor generation and tile raw views.
- ROI or adaptive ROI routes.
- New tests or test infrastructure.
- Project Knowledge domain card edits.

## User constraints

- Keep the task decomposed; implement only task 1.
- Prep must not perform binning, pixel-format normalization, or bit-depth
  conversion.
- Do not add tests without separate approval.
- Do not use legacy sources for code generation.

## Source access rules

Canonical development only. Legacy access is forbidden.

## Assumptions

- The first concrete `PrepStage` slice can be a no-copy full-frame route.
- Tile route should return `Unsupported` until the next approved task.
- Runtime invocation of Prep is a later task.
