## Summary

Add the required TBB CMake dependency for `datapro1_v2` as the build foundation
for the upcoming oneTBB-only tile route.

## Goal

Make `datapro1_v2` configure fail when TBB is unavailable, and link the main
runtime target plus relevant unit-test target with `TBB::tbb`.

## In scope

- Add required TBB package discovery in `datapro1_v2/CMakeLists.txt`.
- Link `TBB::tbb` into `datapro1_v2`.
- Link `TBB::tbb` into `dp1v2_unit_tests` because it already compiles and
  links runtime pipeline code.
- Preserve current runtime behavior.

## Out of scope

- Implementing `OneTbbTileExecutor`.
- Adding a serial tile executor or serial fallback.
- Adding OpenMP, a custom thread pool, or backend dispatch.
- Changing runtime pipeline behavior.
- Changing pipeline, logging, profiling, or application config files.
- Creating or changing automated tests.
- Updating Project Knowledge outside this task card.

## User constraints

- Do not change Project Knowledge outside this task card.
- Do not add compile flags such as `DP1V2_ENABLE_TBB`,
  `DP1V2_ENABLE_ONETBB`, or `DP1V2_USE_SERIAL_TILE_EXECUTOR`.
- Do not add a `backend` field to `tiles.execution`.
- Do not add fallback behavior when TBB is unavailable.
- Keep full-frame runtime behavior unchanged.

## Source access rules

Canonical development route only. Legacy sources are forbidden and must not be
used as implementation sources.

## Assumptions

- This task is limited to build configuration.
- `dp1v2_visual_unit_tests` does not currently need explicit TBB linkage because
  it does not compile or link the tile runtime executor path.
- Future tile executor implementation may require adding new source files and
  revisiting test target linkage.
