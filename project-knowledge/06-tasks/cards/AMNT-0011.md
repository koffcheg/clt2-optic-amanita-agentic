## Summary

Потрібно додати до репозиторію окремий fullstack web-додаток для тестового завдання: Python backend без web-фреймворка та Vue frontend, який показує банки, курси валют, НБУ/середні курси, статистику та найближчі відділення.

## Goal

Надати runnable MVP, який можна запустити локально однією Python-командою, із документованими API endpoint-ами, frontend-інтерфейсом і файлом про використання AI.

## In scope

- Python backend на стандартній бібліотеці без framework dependency.
- Vue 3 frontend через CDN із Vue Router, Pinia та Axios.
- Статичні seeded дані для 5 банків, валют і відділень.
- Best-effort інтеграції з API НБУ, МінФін і Finance.ua з fallback на seeded/mock-safe дані.
- Background scheduler для регулярного оновлення курсів і відділень у межах runtime процесу.
- API для банків, валют, курсів, summary, статистики, nearest branches, significant changes.
- Легка in-memory auth/profile/subscriptions частина як extended functionality.
- README інструкції запуску і LLM_INSTRUCTIONS.md.

## Out of scope

- Зміни production C++ модулів Amanita/DP1/DP2.
- Зміни CMake/Docker/build pipeline існуючого проєкту.
- Додавання automated test framework або test fixtures.
- Production persistence, real email delivery, real deployment hardening.

## User constraints

- Час виконання тестового завдання обмежений 8 робочими годинами.
- Використання AI агентів має бути задокументоване.
- Якість має бути наближена до production без втрати scope control.
- Frontend має бути Vue 2 або 3 зі state manager, router та HTTP client.
- Backend має бути PHP Laravel або Python без фреймворка; обрано Python без фреймворка.

## Assumptions

- Окремий `currency-dashboard/` не змінює існуючі Amanita runtime contracts.
- CDN-залежності для Vue/Router/Pinia/Axios прийнятні для швидкого тестового MVP.
- External APIs можуть бути недоступні під час локального запуску, тому fallback дані потрібні для демонстрабельності.
- Дані користувачів і підписок у цьому MVP зберігаються in-memory.

## Risks

- External APIs may reject requests or change response shapes.
- CDN dependencies require internet access in browser runtime.
- In-memory auth/subscriptions are not durable.
- Statistics are based on snapshots collected during process lifetime plus seeded fallback history.
