## Summary

Extend the existing stage I/O matrix with expected `FrameContext` artifact
records for the existing canonical stages.

## Goal

Make the context reflection requirement concrete for AI agents by showing which
artifact each stage output should register.

## In scope

- Add a `context_artifacts` or equivalent section to the matrix.
- Define the current runtime artifacts:
  - input root artifact: `raw_frame`;
  - radiometric artifact: `radiometric.processing_frame` or equivalent.
- Future expected artifacts for existing but not currently executed. In this task, the agent must add these artifact definitions/placeholders
Future expected artifacts to add:
  - `enhanced_frame`;
  - `detector_response`;
  - `binary_mask`;
  - `candidate_list`;
  - `segment_list`;
  - `validated_object_list`;
  - `measurement_list`.

## Out of scope

- No Stage 0 row.
- No TileScheduler row.
- No CameraProSim row.
- No code changes.
- No implementation of missing stages.
- No requirement to fully revise every future stage row if that would broaden
  the current raw + radiometric correction.

- Keep this task limited to existing current canonical stage matrix correction.

  implemented in current `dp1_v2`.

and `output` carriers while adding expected `FrameContext.artifacts` records for
artifact/provenance reflection.
