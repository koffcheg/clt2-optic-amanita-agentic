## Summary

Add and update focused tests that lock the accepted Stage 2 boundary contract
before Stage 3 and later stages are added.

## Goal

`Stage2BoundaryAdapter`, `InverseMedianFilter`, and full-frame pipeline tests
cover the F32 radiometric path, U8/U16 bypass behavior, PixelRange scaling,
tile workspace selection, and failed radiometric boundary behavior.

## In scope

- Update existing `Stage2BoundaryAdapter` tests.
- Add missing full-frame and tile boundary scenarios.
- Update existing inverse-median visual-unit tests for canonical F32 residuals.
- Update pipeline tests for `stage2.processing_frame` metadata.
- Make minimal production changes only when required by the accepted test
  contract.

## Out of scope

- Domain Project Knowledge updates outside this task card and task index.
- Broad refactoring.
- New dependencies or test infrastructure.
- Changes to public exchange formats or Stage 3 implementation.

## User constraints

- Do not touch Project Knowledge except task cards and their index.
- Unit-test additions and updates are approved.
- `RadiometricStage` must keep reporting its real status.
- Bypass must be formed by concrete `Stage2BoundaryAdapter`.
- `Stage2BoundaryAdapter` must not gain a virtual interface.
- `FrameContext` must not store image payload.
- New production comments and Doxygen comments must be in English.
