## Summary

Update DP1 v2 runtime Prep dispatch so `prep.variant = "tiles"` invokes the
implemented tile layout builder instead of the full-frame Prep overload.

## Goal

Runtime supports both current Prep routes:

- `full_frame` continues through RadiometricStage.
- `tiles` builds `TileDesc[]` and `TileRawView[]`, records Prep timing, and
  returns a controlled failure because the downstream tile pipeline is not
  connected yet.

## In scope

- Add explicit runtime dispatch for `prep.variant`.
- Keep the full-frame runtime route behavior unchanged.
- Invoke `PrepTilesInput` for `prep.variant = "tiles"`.
- Return a controlled failure after successful tiles layout construction.
- Record Prep timing for the tiles route.

## Out of scope

- RadiometricStage tile-route implementation.
- Downstream tile-local pipeline execution.
- ROI or adaptive ROI runtime implementation.
- New automated tests, fixtures, mocks, or test infrastructure.
- Domain Project Knowledge edits.

## User constraints

- Continue the decomposed Prep tiles implementation sequence.
- Do not add unit tests in this task.
- Keep the change local to runtime behavior.

## Source access rules

Canonical development only. Legacy access is forbidden.

## Assumptions

- `PrepStage::process(PrepTilesInput...)` already builds the tile layout and
  non-owning tile raw views.
- `RadiometricStage` full-frame route remains the only downstream route wired
  in the current runtime slice.

## Result

Completed. Runtime Prep dispatch now branches explicitly by
`pipeline_config.stages.prep.variant`:

- `full_frame` invokes `PrepFullFrameInput` and continues to
  `RadiometricStage` with the prepared frame.
- `tiles` invokes `PrepTilesInput`, records Prep timing, and returns the
  controlled failure `prep tiles layout is built, but downstream tile pipeline
  is not connected yet` after successful tile layout construction.
- unsupported runtime Prep variants return an explicit `prep_stage_failed`
  reason and do not reach `RadiometricStage`.

Validation results:
- `cmake --build build-dp1v2-tests --target dp1v2_unit_tests` passed.
- `./build-dp1v2-tests/dp1v2_unit_tests` passed: 105 tests from 7 suites.
- `cmake --build build-host-debug-full --target datapro1_v2` passed.
