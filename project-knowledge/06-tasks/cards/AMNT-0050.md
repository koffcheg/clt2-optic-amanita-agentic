## Summary

Підготувати bounded Stage0.2 slice для software sum binning L0. Поточна задача
є документаційною: вона створює StageSpec і task card draft для майбутньої
реалізації, але не змінює C++ код, config runtime або тести.

## Goal

Майбутній implementation task має отримати формальний route:

```text
FramePacket -> Stage0 software_sum_binning -> CanonicalFrame
```

де `kbin = 1` означає pass-through, а `kbin = 2|4` формує owned binned
`CanonicalFrame` через software sum binning.

## In scope

- Додати StageSpec `dp1.stage_spec.acquisition_input_normalization.sum_binning`.
- Зафіксувати, що Stage0.2 підтримує лише software sum binning.
- Зафіксувати `kbin = 1|2|4`, де `1` означає disabled/pass-through.
- Зафіксувати точну формулу sum binning.
- Зафіксувати U8 widening policy: `U8 -> U16` без clipping.
- Зафіксувати U16 widening policy: `U16 -> U32` без clipping.
- Зафіксувати reject policy для dimensions, які не діляться на `kbin`.
- Зафіксувати coordinate mapping metadata:
  `x0 = xoff + kbin * xb`, `y0 = yoff + kbin * yb`.
- Зафіксувати Stage0.2 full-frame baseline: `xoff = 0`, `yoff = 0`.
- Зафіксувати ownership: `OwnedBinned`, artifact `OwnedByStageOutput`,
  lifetime `StageOutputScope`, status `Available`.
- Зафіксувати StageTiming expectations.
- Додати окрему validation-card для future unit tests без створення тестів.

## Assumptions

- `PipelineConfig.input_route` залишається Stage0 validation contract.
- `software_sum_binning` є canonical Stage0 variant, але current code може ще не
  підтримувати його.
- Current code-backed `PixelFormat` vocabulary може потребувати approved
  extension для `U32` перед U16 sum implementation.
- Coordinate conversion to `SourceFrameGlobal` може бути реалізований у later
  measurement/merge boundary, але Stage0.2 має зберегти metadata для цього.
- Unit validation route має перевіряти algorithm exact sums, widening,
  metadata, artifact registration і timing.

## Risks

- `U32` output for U16 sum may require a future approved `PixelFormat` extension.
- Downstream stages may not yet accept widened binned output.
- If coordinate mapping metadata is not preserved, later measurement output may
  incorrectly use binned-frame coordinates.
- If artifact lifetime is overstated, consumers may read an expired image
  payload.
- If docs are stronger than code implementation, future review must classify the
  difference as an implementation gap rather than silently changing the spec.
