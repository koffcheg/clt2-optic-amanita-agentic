## Summary

Підготувати Stage0.2-pre policy/specification slice для software sum binning.
Поточна задача є документаційною: вона уточнює canonical policy для dynamic
range, widened carrier, ownership/lifetime, FrameContext artifacts, downstream
compatibility і future validation route перед runtime implementation. C++ код,
runtime config, Radiometric і тести не змінюються.

## Goal

Майбутній implementation task має отримати формальний route і заборони:

```text
FramePacket -> Stage0 software_sum_binning -> CanonicalFrame
```

де `kbin = 1` означає pass-through, а `kbin = 2|4` формує owned binned
`CanonicalFrame` через pure software sum binning без прихованого downcast,
scaling або clipping.

## In scope

- Додати StageSpec `dp1.stage_spec.input_normalization.sum_binning`.
- Зафіксувати, що Stage0.2 підтримує лише software sum binning.
- Зафіксувати `kbin = 1|2|4`, де `1` означає disabled/pass-through.
- Зафіксувати точну формулу sum binning.
- Зафіксувати U8/U16 widening policy як canonical baseline `AccumU32` / `U32`.
- Зафіксувати transitional `S32` як невідʼємний accumulated carrier, а не signed residual.
- Зафіксувати окремий lossy compatibility variant як окремий future route, не
  частину `software_sum_binning`.
- Зафіксувати reject policy для dimensions, які не діляться на `kbin`.
- Зафіксувати coordinate mapping metadata:
  `x0 = xoff + kbin * xb`, `y0 = yoff + kbin * yb`.
- Зафіксувати Stage0.2 full-frame baseline: `xoff = 0`, `yoff = 0`.
- Зафіксувати ownership: `OwnedBinned`, artifact `OwnedByStageOutput`,
  lifetime `StageOutputScope`, status `Available`.
- Зафіксувати StageTiming expectations і copy/allocation accounting boundary.
- Зафіксувати explicit pipeline failure, якщо downstream не підтримує widened
  accumulated carrier.
- Додати окрему validation-card для future unit tests без створення тестів.

## Risks

- `AccumU32` / `U32` output requires a future approved `PixelFormat` extension.
- Current code may use `S32` only as transitional невідʼємний accumulated carrier.
- Downstream stages may not yet accept widened binned output and must повернути explicit failure.
- If coordinate mapping metadata is not preserved, later measurement output may
  incorrectly use binned-frame coordinates.
- If artifact lifetime is overstated, consumers may read an expired image
  payload.
- If docs are stronger than code implementation, future review must classify the
  difference as an implementation gap rather than silently changing the spec.
