## Summary

Задача переводить enabled `RadiometricStage` / `inverse_median` output з signed
integer residual route на canonical `CV_32FC1` residual для Stage 2 boundary.

## Goal

Після успішного `RadiometricStage` downstream отримує `stage2.processing_frame`
з `PixelFormat::F32`, `ProcessingDomain::RadiometricResidual` і
`RangePolicy::SignedResidual`. `converted_residual` залишається допоміжним
debug/export представленням і не підміняє canonical Stage 2 output.

## In scope

- Оновити `InverseMedianFilter` residual storage до `CV_32FC1`.
- Оновити residual computation для `float`.
- Оновити clipping auxiliary path, щоб читати `float` residual.
- Оновити `RadiometricStage` selection logic для canonical output.
- Оновити існуючі visual-unit/unit тести.
- Мінімально синхронізувати stage spec українською.

## Out of scope

- Новий boundary adapter interface або `IBoundaryAdapter`.
- Зміни Stage 3 або downstream алгоритмів.
- Масова перебудова Project Knowledge.
- Legacy-based implementation.

## User constraints

- `RadiometricStage` не реалізує pass-through.
- Bypass формує concrete `Stage2BoundaryAdapter`.
- `FrameContext` не зберігає image payload.
- `CV_8U` bypass має бути shallow assignment.
- `CV_16U` bypass має виконувати explicit scaling через `PixelRange`.
- Нові production/Doxygen comments мають бути англійською.
- Project Knowledge mismatch виправити мінімально і точково, українською мовою.

## Source access rules

Canonical development. Legacy access is forbidden.

## Assumptions

- Existing `PixelFormat::F32` and `ProcessingFrame` defaults are sufficient for
  the canonical Stage 2 residual metadata.
- Existing visual-unit and unit test targets are the right validation surface.
