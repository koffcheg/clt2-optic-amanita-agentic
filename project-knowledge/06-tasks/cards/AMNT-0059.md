## Summary

Add focused unit coverage for the implemented PrepStage `tiles` route.

## Goal

Verify real tile grid construction, overlap clipping, non-owning ROI views, and
tiles-route rejection paths for invalid inputs or wrong route variants.

## In scope

- Split the broad Prep tiles unit coverage into named behavior tests.
- Cover no-overlap grid generation for a `5x4` frame with `2x2` tiles.
- Cover overlap and edge clipping for a `6x6` frame with `3x3` tiles and
  overlap `1`.
- Verify `TileRawView` images are non-owning ROI headers into the source
  `CanonicalFrame::image`.
- Verify tiles-route invalid `CanonicalFrame` and non-`tiles` variant rejection.

## Out of scope

- Production PrepStage logic changes unless a test exposes a real defect.
- Runtime pipeline tile dispatch.
- New fixtures, mocks, golden files, or test infrastructure.
- Domain Project Knowledge updates.
