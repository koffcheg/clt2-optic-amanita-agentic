## Summary

Користувач просить зробити deliverable однією папкою, щоб її можна було завантажити окремо від решти репозиторію.

## Goal

Перетворити `currency-dashboard/` на самодостатній Laravel/Vue project root: backend Laravel files, frontend assets, README та AI disclosure мають бути всередині цієї однієї папки.

## In scope

- Перемістити Laravel backend файли з `currency-dashboard/backend/` у корінь `currency-dashboard/`.
- Перемістити Vue frontend із `currency-dashboard/frontend/` у `currency-dashboard/resources/frontend/`.
- Додати/оновити `currency-dashboard/README.md` і `currency-dashboard/LLM_INSTRUCTIONS.md`.
- Оновити Laravel web routes для нового шляху frontend.
- Оновити root README, щоб він вказував на downloadable folder.

## Out of scope

- Зміни Amanita C++ production code/build/tests.
- Додавання нових dependencies поза Laravel/Vue MVP.
- Production DB/queue/mail hardening.

## User constraints

- Один folder для download.
- Залишити Laravel backend direction.

## Assumptions

- Допускаються піддиректорії всередині `currency-dashboard/`; вимога означає один top-level deliverable folder.
- Root repository files можуть лишатися для repo governance, але весь тестовий проєкт має запускатися з `currency-dashboard/`.

## Execution notes

- Consolidated the app so `currency-dashboard/` is the Laravel project root and the only folder needed for download.
- Moved Vue files to `currency-dashboard/resources/frontend/` and updated Laravel web routes to serve from `resource_path('frontend/...')`.
