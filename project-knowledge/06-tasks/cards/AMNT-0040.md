## Summary

Add a minimal C++ artifact registry data model to the current `dp1_v2`
`FrameContext`.

## Goal

Make the current runtime capable of representing raw and radiometric artifacts
without changing stage signatures or algorithm behavior.

## In scope

- Add small enums and structs for artifact metadata.
- Add `FrameArtifactRegistry artifacts;` to `FrameContext`.
- Keep fields sufficient for the current slice:
  - id;
  - kind;
  - domain;
  - ownership;
  - status;
  - semantic name;
  - producer stage;
  - parent artifact id;
  - pixel format;
  - bit depth;
  - geometry.

## Out of scope

- No `cv::Mat` storage in registry.
- No `std::variant` over stage outputs.
- No ownership transfer into context.
- No stage signature changes.
- No new stages.
- No profiling implementation.

## User constraints

- Change only what exists now.
- Keep the implementation minimal.

## Source access rules

Canonical development. Legacy access is forbidden.

## Assumptions

- `FrameArtifactRegistry` can be a simple vector-based container for the first
  slice.
- Hot-path optimization is not required in this metadata-only first step.

## Result

Completed.

Added the minimal metadata-only C++ artifact registry data model to `datapro1_v2` `FrameContext` in `datapro1_v2/include/dp1v2/domain/frame_context.hpp`. The model includes `FrameArtifactKind`, `FrameArtifactDomain`, `FrameArtifactOwnership`, `FrameArtifactStatus`, `FrameArtifactRef`, `FrameArtifactRegistry`, and `FrameArtifactRegistry artifacts;` on `FrameContext`.

The first implementation slice is provenance/metadata only: `FrameArtifactRef` contains stable identity, kind, domain, ownership, status, semantic name, producer stage, parent artifact id, pixel format, bit depth, and geometry. It does not contain `cv::Mat`, pointers, references, `std::variant`, owning handles, stage output storage, or ownership-transfer behavior.

Validation performed:

- Confirmed dependencies `AMNT-0034`, `AMNT-0035`, and `AMNT-0038` are completed.
- Reviewed required context from `AMNT-0034` through `AMNT-0039`, canonical `FrameContext`, memory ownership policy, and current `dp1_v2` domain headers.
- Built `datapro1_v2` with `cmake --build build-host-debug-full --target datapro1_v2`; build completed successfully. Existing warnings about `SingleFramePipelineResult::evidence_path` initializers remain unrelated to this task.
