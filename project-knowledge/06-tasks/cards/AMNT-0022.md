## Summary

This task card prepares the first bounded DP1 code generation iteration.

The first code task is limited to a file-backed input adapter that constructs a canonical `FramePacket` from a grayscale frame source and reports enough evidence for review.

## Goal

Enable the first executable DP1 codegen slice:

```text
FileFrameSource -> FramePacket -> minimal validation/evidence
```

The result must be small, reviewable, and directly tied to canonical DP1 input contracts.

## In scope

- Define the first codegen task boundary.
- Use canonical `FramePacket` as the output boundary.
- Use canonical `PipelineConfig.input_route` as the input metadata/config reference.
- Require a minimal validation/evidence report.
- Keep the task small enough to evaluate agent discipline.

## Out of scope

- CameraProSim.
- POSIX Shared Memory.
- POSIX Message Queue.
- CameraPro runtime integration.
- TileScheduler.
- Full DP1 pipeline implementation.
- Binning / coordinate remapping implementation.
- Candidate extraction, segmentation, or measurement.
- Broad class hierarchy or full DP1 framework scaffolding.
- CMake/build changes unless explicitly approved in a later task.
- Tests/fixtures/directories unless explicitly approved by the reviewer.

## User constraints

- Do not generate the full DP1 structure in one iteration.
- Do not use legacy code as a source of architecture unless a later task explicitly allows it.
- Do not expand the scope from file input to CameraProSim or IPC.
- Prefer a working vertical slice over decorative interfaces.
- Every generated patch must provide evidence.
