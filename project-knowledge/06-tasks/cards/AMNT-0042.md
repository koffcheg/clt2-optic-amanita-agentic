## Summary

Register the current raw frame as the root artifact in `FrameContext` after
successful `FramePacket` creation.

## Goal

Ensure every successfully accepted frame has a `raw_frame` artifact before any
stage output is produced.

## In scope

- Update current `process_single_frame(...)` flow.
- After successful `make_frame_packet(...)` and `build_frame_context(...)`,
  register:
  - id: `raw_frame`;
  - kind: raw frame;
  - domain: raw;
  - ownership: owned by `FramePacket`;
  - producer: input;
  - parent: none;
  - format, bit depth, geometry from `FramePacket`.

## Out of scope

- No source abstraction changes.
- No IPC / CameraProSim changes.
- No Stage 0.
- No result builder changes.
- No tests unless separately approved.

## User constraints

- Only change what exists now.

## Source access rules

Canonical development. Legacy access is forbidden.

## Assumptions

- `FramePacket` is the current root raw input carrier in `dp1_v2`.

- `datapro1_v2/include/dp1v2/domain/frame_packet.hpp`
- `datapro1_v2/include/dp1v2/frame/frame_context.hpp`

## Dependencies

Must be executed after:

- `AMNT-0034`

- `AMNT-0041`

## Planned changes

- Call `register_raw_frame_artifact(...)` in `process_single_frame(...)`.
- Keep failed packet path unchanged.

## Files expected to be touched

## Result

Completed.

Updated `datapro1_v2/src/runtime/pipeline.cpp` so the current runtime registers the accepted raw frame in `FrameContext.artifacts` immediately after successful `make_frame_packet(...)` and `build_frame_context(...)`. The registration uses the AMNT-0041 helper `register_raw_frame_artifact(frame_context, packet_result.packet)`, so the artifact id and metadata remain centralized in the frame-context helper boundary.

The failed packet path remains unchanged: when `packet_result.ok()` is false, `process_single_frame(...)` returns before any raw-frame artifact can be registered. No source abstraction, IPC, CameraProSim, Stage 0, result builder, radiometric artifact registration, missing stages, or tests were changed.

Validation performed:

- Confirmed dependencies `AMNT-0034`, `AMNT-0040`, and `AMNT-0041` are completed before code changes.
- Reviewed the raw-frame registration placement in `process_single_frame(...)` and confirmed it is only on the successful packet path.
- Built `datapro1_v2` with `cmake --build build-host-debug-full --target datapro1_v2`; build completed successfully. Existing warnings about `SingleFramePipelineResult::evidence_path` initializers remain unrelated to this task.
