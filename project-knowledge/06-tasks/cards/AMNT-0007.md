## Summary

Потрібно узгодити наявний DP1_v2 knowledge layer з VKO V20 stage-driven pipeline та підготувати перший контрольований agent workflow для переходу від великого ТЗ до stage/interface cards.

Ця задача не передбачає production code changes.

## Goal

Підготувати мінімальну основу для LLM-first / card-driven роботи над DP1 pipeline:

- зіставити existing DP1 cards, DP1_v2 plan і VKO V20;
- визначити, яких stage interface cards бракує;
- підготувати один pilot stage interface draft;
- перевірити, чи агент може виконати knowledge-only задачу без scope drift.

## In scope

- аналіз existing DP1 knowledge;
- аналіз DP1_v2 plan;
- зіставлення з VKO V20 / 8-stage pipeline;
- gap matrix;
- список required stage interfaces;
- draft однієї pilot stage interface card;
- iteration report після агентного прогону.

## Out of scope

- production code changes;
- CMake / build changes;
- Docker / deployment changes;
- зміни DP1 -> DP2 runtime contract;
- повна реалізація DP1 pipeline;
- створення всіх малих ТЗ для 8 етапів;
- створення нових task cards без явної вказівки.

## Required stage interfaces to check

- `IPrepStage`
- `IRadiometricStage`
- `IEnhancementStage`
- `IMatchedFilterStage`
- `ICandidateExtractionStage`
- `ISegmentationStage`
- `IObjectFilterStage`
- `IMeasurementStage`

## Pilot stage

Перший pilot stage для draft card:

- `IMeasurementStage`

Причина вибору:

- stage напряму пов'язаний з виходом DP1;
- важливий для подальшої сумісності DP1 -> DP2;
- дозволяє перевірити, чи existing structures/cards достатні для формального stage interface.

## Deliverables

1. Gap matrix:
   - що вже покрито existing DP1 cards;
   - що вже покрито DP1_v2 plan;
   - що вимагає VKO V20;
   - чого бракує для stage-driven pipeline.

2. Список required stage interface cards.

3. Draft однієї pilot stage interface card:
   - `IMeasurementStage`.

4. Iteration report у форматі з `AGENTS.md`.

## Execution constraints

- працювати строго в межах цієї task card;
- не створювати нові task cards, sub-cards, фази або ітерації без явної вказівки;
- не змінювати production code;
- не змінювати CMake, build scripts, Docker або deployment logic;
- не змінювати `.vscode`, local settings або файли з absolute machine-specific paths;
- не дублювати existing DP1_v2 plan або bottlenecks analysis;
- якщо existing cards покривають частину вимог, посилатися на них замість дублювання.

## Validation approach

Knowledge-only validation:

- перевірити, що всі висновки спираються на existing repo files або VKO V20;
- явно позначити missing або unclear areas;
- не вигадувати code-level facts без перевірки коду;
- не створювати implementation plan ширший за цю task card.

## Definition of done

Задача вважається виконаною, якщо є:

- gap matrix;
- список 8 required stage interfaces;
- draft `IMeasurementStage` interface card;
- короткий iteration report;
- немає production code changes;
- немає `.vscode` / local path pollution;
- немає нових task cards без явної вказівки.
