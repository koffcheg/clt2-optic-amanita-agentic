## Summary

Ця task card обмежує виправлення review blockers для поточного FrameContext
registry/provenance baseline у PR #28. Мета - зробити C++ slice не слабшим за
canonical claims щодо lifetime/status і мінімального stage-level profiling.

## Goal

Після виконання current raw + radiometric slice має:

- явно розрізняти payload ownership, lifetime і metadata-only artifact records;
- не показувати radiometric artifact як live payload, якщо `FrameContext` не
  зберігає typed reference/pointer;
- мати мінімальний `StageTiming`/`FrameProfiling` відповідно до
  `PROFILING_POLICY.md`;
- мати unit coverage для raw і radiometric artifact registration semantics.

## In scope

- Додати C++ lifetime semantics до `FrameArtifactRef`.
- Вирівняти raw і radiometric artifact registration.
- Додати мінімальні P2 stage-level profiling records у `FrameContext`.
- Інструментувати current input/raw boundary і radiometric execution у
  `process_single_frame`.
- Додати focused unit tests без fixtures/datasets/golden files.
- Оновити лише релевантні canonical cards/docs, вже пов'язані з PR scope.

- DP2 behavior.

## Result

- Додано `FrameArtifactLifetime` у C++ `FrameArtifactRef`.
- Raw artifact реєструється як `OwnedByFramePacket + InputBoundary + Available`.
- Radiometric artifact реєструється як
  `OwnedByStageOutput + StageOutputScope + MetadataOnly`, тому запис не обіцяє
  live payload reference у `FrameContext`.
- Додано мінімальний P2 `StageTiming` / `FrameProfiling` за
  `PROFILING_POLICY.md`.
- Поточний runtime записує timing для input boundary і executed radiometric
  stage.
- Додано unit tests для raw/radiometric artifact semantics, lookup behavior і
  мінімального `StageTiming`.
- Оновлено релевантні canonical cards українською.
- Stage0, DP2, CameraSim/CameraProSim runtime behavior і OverlayRunner не
  змінювалися.
