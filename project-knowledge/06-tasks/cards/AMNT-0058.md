## Summary

Implement the Prep `tiles` L1 route for the current DP1 v2 slice.

## Goal

Replace the temporary `prep tiles route is not implemented` result with real
tile descriptor and non-owning raw ROI view generation from `CanonicalFrame`.

## In scope

- Validate the `CanonicalFrame` input for the tiles route.
- Build `TileDesc[]` using core tile rectangles, overlap expansion, clipping,
  and tile-local valid areas.
- Build matching `TileRawView[]` as non-owning ROI views into
  `CanonicalFrame::image`.
- Update existing PrepStage unit coverage for the implemented behavior.

## Out of scope

- End-to-end runtime pipeline tile execution.
- Radiometric tile dispatch integration.
- ROI or adaptive ROI variants.
- Pixel-format normalization, bit-depth conversion, binning, resize, border
  materialization, or image copying.
- Domain Project Knowledge card edits.

## User constraints

- Continue the decomposed Prep tiles implementation sequence.
- Touch only the listed PrepStage files unless validation reveals a local
  compile issue.
- Do not use `clone()`, `copyTo()`, `convertTo()`, `resize()`, or
  `copyMakeBorder()` in Prep.

## Source access rules

Canonical development only. Legacy access is forbidden.

## Assumptions

- Existing `PrepTilesParametersConfig` values are already resolved and validated
  by configuration loading.
- `TileRawView::image` can be represented by OpenCV ROI header construction
  over the original `CanonicalFrame::image`.

## Result

Completed. `PrepStage::process(PrepTilesInput...)` now builds the L1 tiles route from `CanonicalFrame`:

- validates the canonical frame carrier before tile construction;
- builds clipped `TileDesc::roi_with_border` and tile-local `valid_area`;
- builds matching `TileRawView` carriers with metadata copied from the canonical frame;
- uses `frame.image(desc.roi_with_border)` for non-owning OpenCV ROI views;
- does not call `clone()`, `copyTo()`, `convertTo()`, `resize()`, or `copyMakeBorder()`.

Updated the existing PrepStage unit test to assert descriptor geometry, edge clipping, metadata propagation, and non-owning ROI view behavior.
