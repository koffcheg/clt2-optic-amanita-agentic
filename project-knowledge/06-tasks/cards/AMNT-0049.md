## Summary

Implement Stage0.1 CanonicalFrame baseline in `datapro1_v2` after the AMNT-0048 documentation review.

## Goal

Runtime flow becomes `FramePacket -> Stage0 acquisition -> CanonicalFrame -> RadiometricStage` for the current full-frame route.

## In scope

- Add explicit `CanonicalFrame` carrier.
- Add Stage0 acquisition input normalization stage with pass-through behavior.
- Validate source frame against `PipelineConfig.input_route`.
- Register `canonical_frame` artifact with parent `raw_frame`.
- Record StageTiming for `acquisition`.
- Make radiometric consume `CanonicalFrame`.
- Preserve current SWIR smoke route.

## Out of scope

- Binning arithmetic or Stage0.2.
- ROI, tiles, Stage1.1 Prep full-frame layout.
- CameraProSim runtime.
- IPC shared-memory layout.
- DP2, OverlayRunner.
- Broad refactor.
- Config rename unless unavoidable.
- New automated tests without explicit approval.

## User constraints

- Do not implement binning in Stage0.1.
- Do not make Prep perform normalization.
- Do not treat FrameContext as owner of heavy image payload.
- Do not use legacy as design source.
- Do not create tests without approval.

## Source access rules

Canonical development. Legacy access is forbidden.

## Assumptions

- `pipeline.input_route` is the Stage0.1 validation contract.
- Current `FramePacket` payload lifetime is sufficient for a borrowed read-only `CanonicalFrame` within the frame processing boundary.
- The current runtime route is full-frame radiometric before later Prep implementation slices.

See `canonical_sources`.

## Planned changes

- Add `CanonicalFrame` domain structure and Stage0 pass-through stage.
- Extend pipeline config parsing with `pipeline.acquisition`.
- Add canonical frame artifact registration helper.
- Route radiometric full-frame input through `CanonicalFrame`.
- Add build wiring and default config acquisition fragment.

- Current `FramePacket` builder can validate input_route; Stage0 must become the explicit validation point without silently converting metadata.
- Borrowed `cv::Mat` semantics must not be reported as owned by FrameContext.
