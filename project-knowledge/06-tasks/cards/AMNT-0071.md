# AMNT-0071

## Description
Implement DP1_v2 Stage0 runtime average binning mode with kbin={1,2,4} and explicit unsupported behavior for non-divisible geometry.

## Scope
- Stage0 input_normalization runtime behavior.
- Pipeline config parsing/resolution for Stage0 binning mode.
- Unit tests for Stage0 binning and Stage1 prep compatibility.

## Constraints
- Average only; no sum/AccumU32 route.
- No camera input work.
- No Stage2+ tile execution connection.

## Relevant files
- datapro1_v2/src/stages/input_normalization_stage.cpp
- datapro1_v2/src/config/config.cpp
- tests/unit/dp1/t_dp1v2_input_normalization_stage.cpp

## Expected changes
- Add disabled/average mode + kbin 1/2/4 config resolution.
- Implement deterministic block-average binning for U8/U16.
- Preserve output type/format and pixel range metadata.

## Risks
- Overflow/rounding correctness for U16.
- Behavior mismatch for non-divisible dimensions.

## Validation approach
Build DP1_v2 targets and run ctest in requested build directory.
