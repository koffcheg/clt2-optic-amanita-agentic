# DP1_CARDS_INDEX

## Status

This file is kept as a compatibility index for the former DP1 cards layout.

The former `02-dp1/cards/*.md` files were classified and moved under `02-dp1/legacy/`. They are legacy-reference cards and must not be used as target architecture for canonical DP1.

For canonical DP1, start with:
- `canonical/DP1_CANONICAL_INDEX.md`

For legacy DP1 analysis, start with:
- `legacy/DP1_LEGACY_INDEX.md`

Legacy access during canonical development requires explicit task-card permission.
