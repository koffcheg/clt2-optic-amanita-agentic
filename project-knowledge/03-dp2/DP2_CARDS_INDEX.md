# DP2_CARDS_INDEX

## Status

This file is kept as a compatibility index for the former DP2 cards layout.

The former `03-dp2/cards/*.md` files were classified and moved under `03-dp2/legacy/`. They are legacy-reference cards and must not be used as target architecture for canonical DP2.

For canonical DP2, start with:
- `canonical/DP2_CANONICAL_INDEX.md`

For legacy DP2 analysis, start with:
- `legacy/DP2_LEGACY_INDEX.md`

Legacy access during canonical development requires explicit task-card permission.
